# Creative velocity needs a governance operating system.

A browser-local workbench for mapping synthetic-media, creator-rights, disclosure, provenance, and incident-response decisions.

**Live:** https://aloha-third-asset.vercel.app

## Repository contents

`next.config.js`, `package.json`, `pages`, `public`, `styles`, `vercel.json`

## Local development

```sh
npm ci
npm test
npm run build
```

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
